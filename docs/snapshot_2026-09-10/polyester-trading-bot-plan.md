# Polyester Trading Bot — Project Plan

## Цель
Собрать полноценного торгового бота (Telegram-интерфейс) поверх Polyester API (devnet), способного открывать/закрывать позиции, следить за балансом и управлять рисками.

## Текущий статус
- ✅ Аутентификация Ed25519 (подпись запроса) — реализована и проверена (`polyester_signed_request.py`)
- ✅ Простой Telegram-бот с ручным вводом qty/price для Limit Buy — реализован (`polyester_telegram_bot.py`)
- ✅ API-ключ создан, права выданы (Spot Trading: Write, Balances: Read)
- ⏳ Остальные функции API — не разобраны

## Этап 2 — Архитектура бота

Определить до начала кодинга:

1. **Стратегия входа/выхода** — на чём бот будет принимать решения (ручные сигналы через Telegram? Технические индикаторы? Просто ручной триггер, как сейчас?)
2. **Риск-менеджмент** — обязательные TP/SL на каждой позиции? Максимальный размер позиции? Максимальная дневная просадка (dead man's switch)?
3. **Источник цены** — REST-поллинг (просто, но с задержкой) или WebSocket (сложнее, но реалтайм)
4. **Хранение состояния** — где бот хранит открытые позиции, историю, конфиг (файл/SQLite/просто память процесса)
5. **Аварийная остановка** — команда `/panic` или `/stopall`, которая отменяет все ордера и закрывает позиции
