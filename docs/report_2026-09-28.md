Example: deposit flow_4xW7RUSVcPK, 2 tXRP from ripple-testnet. The flow page shows Principal Amount 2 tXRP, Network Fee None, Credited Amount 1.8 tXRP. The API reference says request fees are exposed separately in request_fee when a fee applies.

## Сообщение 3 (английский)

Polyester Scan website, re-checked 28.09 18:08–18:09 UTC.

The Solana step link is broken. On flow_SMQSpzMh1NM the Deposit Seen step links to the Solscan devnet tx page with the signature lowercased (45bqaafmzuhj...), while the Source Tx row uses the correct 45bQAAfmzUhj.... Base58 is case-sensitive, so the lowercased link opens nothing; getSignatureStatuses on Solana devnet returns "Invalid param: Invalid" for it. The step txRef goes through trim().toLowerCase() before the external link is built.

Chain and native-token links go to mainnet for Solana, Bitcoin and Litecoin. On deposit and withdrawal flow pages the Source or Destination Chain link and the Token (Native) link open the Solscan mainnet home page, the mempool explorer home page and the litecoinspace home page. They drop the cluster=devnet parameter and the testnet path from explorerUrl, because the link is built from the URL origin only. Transaction and address links on the same pages are correct.

Export Data is broken on two tables. Tokens: in all 40 rows the Token, Source Chain, Polyester Chain Contract Address and Source Chain Token Address columns contain the same Polyester contract address, and # and supply are empty. Flows: the Asset column is empty in every row (amounts like 1000 and 14.2 with no asset), Status holds the internal step name settlement instead of Completed, and there are no tx hashes.

Internal transactions are not indexed. The internal-transactions list is empty for the whole chain, raw-trace returns 500 "Error while raw trace fetching", and debug_traceTransaction is not available on the RPC. The Internal Txns tab still says "No internal transactions for this transaction", even for proxy calls like 0x10c5d7a58a06c72835251cb24f2509b9b60797201ca2763fb3ab2e4ae6477c14, where the logs come from five different contracts. If tracing is off on purpose, the tab should say so instead.

Home page exchange stats are placeholders. Total Txns (Polyester Exchange) 11,124,982 and 123,922 TPS are hardcoded in the page bundle as {txs:11124982,tps:123922}, and the TVL card is hardcoded to $0.00 and 0.00%.

Total Txs on the home page comes from the Blockscout stats counter, which is stuck: total_transactions has been 87087 since 16:19 UTC, and total_blocks is 2966931 while the latest block is 2978239 (18:09 UTC).

Minor: the debug page /dev/sentry-test-client is public ("Client Sentry Test" with a "Throw client exception" button). GET /api/v2/blocks/99999999999999999999 on the Scan API returns 500 "Internal server error" instead of 404. Every page is served with html lang="%lang%".
