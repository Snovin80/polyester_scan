пообещал, что обратные кавычки пройдут автомодерацию Discord → тайм-аут.

**Why:** правила в [[report-style-polyester]] были, я их пропускал. Автор не
технарь и проверить может только переспросом — каждый пропуск стоит ему нервов.

**How to apply — порядок, без исключений:**
1. До показа текста: каждое утверждение — живой вызов СЕЙЧАС, документация
   (страница справочника, не только MCP), обратная проверка («нет поля» —
   передать поле). Формулировка не шире проверенного (один компьютер, какие
   пути, какое время UTC).
2. Текст показываю ТОЛЬКО вместе со строкой «Проверено:» — по пунктам, чем
   подтверждено каждое утверждение (вызов + время / страница доков / обратная
   проверка). Нечем подтвердить — утверждения в тексте нет.
2а. В текст ОБЯЗАТЕЛЬНО входит сырой ответ биржи (тело JSON дословно + время
   UTC + Content-Type) на главный пункт — снимать его ДО показа текста.
   27.09 забыл, автор: «каждый раз я за тобой подтираю, я устал».
2б. Перед показом пройти этот список глазами пункт за пунктом: живой вызов,
   доки, обратная проверка, сырой ответ, формулировка не шире проверенного,
   время UTC, без ссылок если Discord, стиль [[report-style-polyester]].
3. Одна окончательная версия. Сомнение — сказать ДО текста, а не править после.
3а. Любая правка текста — ВСЕГДА полный текст целиком для копирования, НИКОГДА
   «замените абзац/строку» или «вставьте после второго абзаца». Автор 27.09:
   «как я тебе абзацами менять буду». Он копирует блок в телегу целиком.
3б. Под КАЖДЫМ английским текстом — полный русский перевод (автор 28.09:
   «ты забыл что мне нужен перевод»). Несколько отчётов — каждый отдельным
   блоком целиком, никаких «текст 1 — тот, что выше».
3в. До показа — grep журнала по «ОТПРАВЛЕНО» и по ключевым словам находки:
   не слали ли это или родственное. Родственное уже отправленному —
   подавать как дополнение, ссылаясь на прошлое сообщение по смыслу, без
   номеров пунктов и дат отчётов («same issue as the triggers reference I
   mentioned earlier»). Автор сам отдельно команде НЕ пишет — всё
   отправленное есть в журнале (28.09), журнал = полный список.
3г. Не фантазировать, а делать: указания автора выполнять сразу, не
   переспрашивать «заменить правило?» (28.09). Никаких «около», «same
   second», «any query» без замера — время только из снятого ответа.
   Любая правка текста = снова весь чек-лист п.1–2б до показа.
4. «Отправлено» в CLAUDE.md — только после слов автора «отправил» или скрина
   из самого чата команды (с их ответом). «Избранное» = черновик.
5. Про чужие системы (модерация, поведение сайта) — «не знаю», не догадка.
   См. [[polyester-discord-no-urls]].
