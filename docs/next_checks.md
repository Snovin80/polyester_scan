## A. Самое перспективное (рядом с уже найденным)

1. **Ссылка «external explorer» на странице сети** `/supported-chain/{id}`. Быстро.
   Та же функция origin, что в находке 2 → у Solana/BTC/LTC скорее всего ведёт в основную сеть.
   Проверить `href` в HTML для id 1, 3, 8.
2. **Регистр хэшей XRP в ссылках шагов.** Быстро. Шаги переводят хэш в нижний регистр (находка 1).
   В API хэши XRP в верхнем (`D0B960EF…`). Открыть обе ссылки на `testnet.xrpl.org` — работает ли нижний.
3. **Депозиты ниже минимума.** В XRP/SOL есть операции `1.8 → 1.8`, `0.009 → 0.009` при минимуме 2 и 0.01
   (доки: «deposits below the minimum will be lost»). Выяснить: это депозит ниже минимума, зачисленный
   без комиссии, или API записал в первый шаг уже «чистую» сумму. Сверить с суммой в исходной сети.
4. **Выводы (withdraw flows).** Комиссия вывода = networkFee (доки: одна ставка в обе стороны)?
   Есть ли ссылка на транзакцию в сети назначения, в нужной ли она сети, совпадает ли сумма доставки
   с цепочкой назначения. Ссылки у вывода Solana (`flow_PtjQaxSbm23`) — пока без tx назначения.
5. **Сумма операции против исходной сети.** Principal у депозита = сумма в самой исходной сети:
   Sepolia (RPC), BTC/LTC testnet (API mempool/litecoinspace), Solana devnet (`getTransaction`), XRP testnet.
   Сюда же — хэши автора (Zipper, Sepolia).
6. **Все 16 сетей на страницах операций** — по одной операции на сеть: все `href`, регистр, сеть.
   Сейчас проверены Solana, Bitcoin, Litecoin (+ по коду остальные).
