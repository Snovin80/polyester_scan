# Для автора: что проверить своими руками

Только то, во что я упёрся из облака (Cloudflare, вебсокеты). Всё остальное проверяю сам.

## 1. Ссылка на операцию XRP в нижнем регистре — открывается ли?
testnet.xrpl.org из облака не показывает транзакции (у него вебсокеты). Открыть по очереди:
- `https://testnet.xrpl.org/transactions/D0B960EF4BC26A849FB818885AD0802E2476824D668749C7205E91BF7140C2A4` (правильная)
- `https://testnet.xrpl.org/transactions/d0b960ef4bc26a849fb818885ad0802e2476824d668749c7205e91bf7140c2a4` (так ссылается шаг «Deposit Seen»)
Если первая показывает транзакцию, а вторая нет — скрины обеих (расширение находки 1).

## 2. Поиск операции на сайте — показывает ли результат?
Ответ поиска операций из облака блокирует Cloudflare. В поиске сайта вверху вставить по очереди:
- `45bQAAfmzUhjAAwe3XJsPDxPS8PtJa6mLxkMgU31SQYts7H8rQbTHTFajeSZr4XXKZQpbVtQQSTSfW1wLRxfhMHJ` — ждём операцию flow_SMQSpzMh1NM (0.01 tSOL)
- `flow_SMQSpzMh1NM` — ждём ту же операцию
Скрин выпадающего списка для каждого.

## 3. Выгрузка CSV на странице Flows
Из облака таблица операций не грузится. `testnet.polyesterscan.com/flows` → «Export Data» → открыть файл:
в колонках должны быть тип, аккаунт, суммы, хэши. Если там повтор одного значения во всех колонках (как у токенов,
находка 17) — прислать файл или скрин.

## (по желанию) Тесты тестовыми монетами — самые сильные, делаются только вашими руками
- депозит ровно на минимум и чуть меньше (что покажет обозреватель; по докам ниже минимума — «will be lost»);
- депозит с лишними знаками (0.0123456789 ETH при 6 знаках) — сколько зачислено;
- два перевода на адрес депозита одной транзакцией — должно быть две операции;
- вывод небольшой суммы XRP/SOL — будет ли «Network Fee None» (находка 3) и ссылка на доставку (находка 14).
Пришлёте хэши — сверю по всем трём источникам.
